| **CVE-2026-53840** | TBD | MCP Streamable HTTP 跨域重定向洩漏自訂 header | < 2026.6.6 | 2026.6.6 | 2026-06-17 |

**CVE-2026-53840 細節**：
- 攻擊面：MCP Streamable HTTP server 使用 operator-configured custom headers
- 弱點：當 MCP endpoint 回應 cross-origin redirect 時，custom headers 會被轉發到另一個 origin
- 影響：洩漏 configured header 內容（不影響 OpenClaw 自身憑證）
- 本機評估：✅ 不受影響（mcporter 未啟用）
