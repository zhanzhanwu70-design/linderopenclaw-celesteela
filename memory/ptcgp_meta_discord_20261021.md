## 📈 環境關鍵洞察

**【水系＋電系 = 當前雙強】**
首次出現「群組級」水系與電系同時站上 51.2%+。水系勝在穩健（對路卡利歐 57.9%、對哈克龍 60.7%、對草系 57.5%）；電系勝在效率（壓蜂女王 67.8%、壓哈克龍 32.8% 是弱點）。水系適合求穩，電系適合針對。

**【路卡利歐系 = 環境最大效率黑洞】**
格鬥/火系合計 18.50% 使用率是最大族群，但群加權 AWR 只有 49.59%。單看路卡利歐 ex + 路卡利歐 是 49.18%，對七夕青鳥只有 28.6%、對哈克龍 36.1%、對草系 36.8%。人氣第一 ≠ 效率第一，這是 B4a 全期最穩的規律。

**【RPS 對位結構成型 — 單體 AWR 高的牌組有明確剋星】**
- 路卡利歐 → 蜂女王（65.9%）→ 水君（57.9%）
- 水君 → 哈克龍（60.7%）→ 路卡利歐（63.5%）
- 七夕青鳥壓路卡利歐 68.3%，但輸蜂女王 37.3%、輸胡帕 30.5%
- 自爆磁怪壓蜂女王 67.8%，但輸哈克龍 32.8%
👉 結論：**沒有無敵牌組，只有對位正確的牌組**。今天想贏，第一步是讀對手而不是讀環境。

**【七夕青鳥系的隱藏內戰】**
超級七夕青鳥 ex + 太陽伊布 單體 51.83%（N=6,215，全環境最大樣本），但同系其他分支拖累整體：純超級七夕青鳥 48.98%、鈴鐺響 45.00%、滾滾蛋 48.73%。**只有太陽伊布分支值得玩**。

**【火箭隊系持續崩壞】**
群加權 45.68%，是唯一低於 47% 的族群。火箭隊拉達 + 阿羅拉九尾 39.85%（261勝378敗）連續數週霸榜最差。第一名火箭隊雙尾怪手 + 胡帕 也只有 48.76%。
